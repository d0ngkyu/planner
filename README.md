# 플래너 (일·주·월)

Android 설치 앱 작업: [빌드·설치·업데이트 및 현재 지원 범위](ANDROID.md). 기존 화면/기능을 공유하며 기능·디자인 개선은 단계적으로 진행한다.

폰과 PC에서 같은 데이터를 쓰는 개인 플래너. 설치 없는 웹앱(PWA)이며 홈 화면/바탕화면에 앱처럼 추가할 수 있다.

## 기능
- **일간**: 할 일(체크)·시간 일정, 진행률, 밀린 할 일 "오늘로" 이동, 오늘의 메모
- **주간**: 월~일 7칸, 칸별 빠른 추가, 이번 주 목표 체크리스트, 주간 메모
- **월간**: 달력(PC는 제목, 폰은 점 표시), 선택한 날 일정, 이번 달 목표, 월간 메모
- 반복(매일/평일/매주/매월/매년, 종료일), 색상, 메모, 검색, 되돌리기
- 빠른 입력: `14:00 회의`, `오후 3시 미팅`, `9시 반 운동` → 시간 일정으로 자동 인식
- 오프라인 사용, 다크 모드, JSON 내보내기/가져오기
- **업적**: 완료·등록·일정 시간·연속일 미션, 보상으로 칭호/앱 안 아이콘/테마, 레벨
- **루틴 묶음**, **집중 타이머**, **컨디션 기록**, **미루기 횟수·쪼개기 제안**, **끌어서 날짜 옮기기**(폰은 길게 눌러서)
- **기록 화면**: 실행 잔디, 주간 리포트(공유), 컨디션 그래프, 집중 기록
- 알림(Android): 일정 시간, 아침 계획, 밤 체크+재알림
- 단축키(PC): ←/→ 이동, T 오늘, D/W/M/S 보기, N 새 항목, / 검색 · 폰은 좌우 스와이프

## 실행
정적 파일만 있으면 된다. 로컬 확인: `python3 -m http.server 8765` 후 http://localhost:8765
배포: GitHub Pages(Settings → Pages → main / root). 폰에서 주소 열기 → "홈 화면에 추가".

## 동기화 켜기 (폰 ↔ PC)
설정 전에는 각 기기에만 저장된다. Firebase 무료 플랜으로 켠다.
1. https://console.firebase.google.com 에서 프로젝트 생성
2. Authentication → 로그인 방법 → **이메일/비밀번호** 사용 설정, 승인된 도메인에 `<계정>.github.io` 추가
3. Firestore Database 생성 → 규칙 탭에 `firestore.rules` 내용 붙여넣고 게시
4. 프로젝트 설정 → 웹 앱 추가 → 표시되는 `firebaseConfig` 값을 `firebase-config.js`에 넣고 푸시
5. 각 기기에서 ⚙ → 이메일로 연결. 첫 기기에서 가입 후 다른 기기에서 같은 계정으로 로그인한다. 기존 기기 데이터는 첫 로그인 때 자동으로 합쳐진다. Android는 설정 포함 APK 재빌드가 필요하다.

동기화 규칙: 항목별로 마지막 수정이 이긴다(삭제 포함). 같은 항목을 두 기기에서 오프라인으로 동시에 고치면 나중 수정본만 남는다.
서버 트랜잭션으로 오래된 변경이 최신 삭제를 되살리는 것을 막으며 삭제 표시를 보존한다. 첫 연결 계정과 다른 계정은 로컬 기록 유출 방지를 위해 차단한다. 계정 전환/데이터 분리는 아직 지원하지 않는다. 현재 저장소 `firebaseConfig=null`이므로 실제 서비스는 미연결이다.

## 0.2 기능
- **미정 보관함**: 날짜 없이 카드로 저장, 편집에서 미정 체크를 끄고 원하는 날짜를 정한다.
- **순서 변경**: 일간 화면에서 순서 변경 → 위/아래 버튼. 시간/반복 자체는 유지하며 해당 날짜에만 적용한다.
- **18개 카테고리**: 일반, 운동, 독서, 자기계발, 공부, 업무, 생활, 집안일, 건강, 식단·요리, 돈 관리, 쇼핑, 취미, 창작, 관계·약속, 여행·외출, 행정·서류, 일기·회고. 제목만 빠르게 등록 가능하며 상세 화면에서 활동별 기록을 작성한다. 카테고리를 바꿔도 이전 양식 내용은 보존하고 다시 선택하면 표시한다. 검색/JSON 백업/동기화 대상이다.
- **간단한 첫 화면**: 오늘 할 일 중심, 추가 기록은 접기, 전체 카테고리 펼치기, 설정에서 큰 글자와 업적.
- **Android 홈 위젯**: 홈 화면의 위젯 목록 → 플래너 → 오늘 할 일. 최대5개와 남은 개수, 마지막 앱 기록 시각 표시. 탭하면 앱을 연다. 앱 저장/복귀 시 갱신하며 앱에서 만든 앞으로8일 스냅샷을 사용한다. 백그라운드 서버 동기화/위젯에서 직접 완료는 지원하지 않는다. 실제 런처 검증 필요.

## 알림 켜기 (Android 권장, 앱 꺼져 있어도 옴)
동기화를 먼저 켠 뒤:
1. Firebase 프로젝트를 **Blaze(종량제)** 로 변경 (Cloud Functions 실행에 필요, 개인 사용량은 무료 한도 안일 가능성이 높지만 보장 아님 — 예산 알림 설정 권장)
2. 프로젝트 설정 → 클라우드 메시징 → 웹 푸시 인증서 생성 → 키를 `firebase-config.js`의 `vapidKey`에 넣기
3. PC에서 `npm i -g firebase-tools` → `firebase login` → `firebase use <프로젝트ID>` → `firebase deploy --only firestore,functions`
   (선택) 함수 환경변수 `APP_URL=https://<계정>.github.io/planner/` 를 `functions/.env`에 넣으면 알림 클릭 시 정확한 주소로 열림
4. 폰 크롬에서 앱 열기 → 홈 화면에 추가 → ⚙ → "이 기기에서 알림 켜기" → "테스트 알림"

보내는 알림: 항목별 일정 알림(정시~1시간 전), 아침 계획 알림, 밤 체크 알림(남은 할 일이 있으면 30분 간격 2회 재알림). 서버는 서울 시간 기준 매 분 `functions/index.js`의 `tick`이 확인한다.

## 구조
| 파일 | 역할 |
|---|---|
| `store.js` | 날짜·반복·병합 등 순수 로직 (DOM 없음, 테스트 대상) |
| `app.js` | 화면 렌더링/이벤트 |
| `sync.js` | Firebase 동기화·푸시 등록 어댑터 (`firebase-config.js`가 null이면 꺼짐) |
| `notify.js` | 알림 판단 순수 로직 (서버와 테스트 공용) |
| `functions/` | 매 분 알림 발송 Cloud Functions (서울 리전) |
| `sw.js` | 오프라인 캐시 — 앱 파일 바꾸면 `VERSION` 올리기 |
| `tests/` | `npm test` (Node 18+) |

협업 규칙은 `COLLAB.md`, 작업 상태는 `TASKS.md`.

## 0.3 하루 원판
- 일간 화면의 원판/목록 전환. 기본 원판이며 선택을 기기에 보존한다.
- 00시가 위, 06시 오른쪽, 12시 아래, 18시 왼쪽인 24시간 원판. 시간 일정은 카테고리/항목 색상으로 표시하고 현재시간 바늘은 오늘만 표시, 30초마다 갱신한다.
- 구역 선택 → 아래 카드에서 내용/활동별 기록 열기·할 일 완료. 좁은 구역은 ‘시간 일정 모두 보기’의 큰 버튼이나 키보드로도 선택 가능하다. 끝 시간이 없거나 시작과 같으면 1시간으로 표시한다고 안내한다.
- 겹치는 시간은 동심원, 자정을 넘는 일정은 당일 부분/전날 연속 부분으로 표시. 전날 반복할 일 완료는 해당 발생일에만 반영한다.
- 시간이 없는 당일 항목은 아래 목록, 날짜 자체가 없는 항목은 기존 보관함. 순서 변경은 목록 보기로 전환한다. 기존 레코드/동기화/위젯 모델 변경 없음.

## 0.4 오늘의 한 조각과 영감함
- 360개 글: 직접 쓴 글 348개, 전래 속담 10개, 출처를 확인해 자체 의역한 고전 2개. 명언뿐 아니라 짧은 에세이·질문·실천 제안을 담았다.
- 오전(5~12시)·오후(12~18시)·밤에 새 글. 글을 누르면 다음 글, 출처를 누른 뒤 이전 글로 되돌리기. 같은 시간대에서는 360개를 한 바퀴 보기 전 중복하지 않으며 현재 순서를 기억한다.
- ♡ 저장 → 영감함: 응원·성장·쉼·집중·관계·발견의 6가지 느낌과 12개 하위 주제별로 모은다. 각 모음 아래 비슷한 주제의 미저장 글 3개를 추천한다. 오프라인 태그 기반이며 외부 AI 서비스는 사용하지 않는다.
- 저장 당시 본문/출처를 보존하고 JSON 백업·검색에 포함한다. Firebase 실제 연결은 아직 미완료다.
- 앱 안/Android 위젯/설치 앱 아이콘에 심플한 달력 캐릭터. 방문·완료·하루 계획 완료·2일 휴식·5일 휴식·복귀에 따라 6가지 표정. 설정에서 아이콘 자동 변경을 끌 수 있다.
- Android는 6시간 간격의 OS 예약 작업으로 휴식 상태를 확인한다. 절전과 런처에 따라 시점이 늦고 기존 바로가기는 새 아이콘을 바로 반영하지 않을 수 있다. 실제 폰 설치/런처 전환은 미검증이다.
